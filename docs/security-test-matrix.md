# 安全验收矩阵

本矩阵按实施阶段列出测试场景与验收目标。阶段 1 的执行结果见[验证记录](stage-1-validation.md)；授权、写入、删除、GUI 与跨平台场景按表中阶段推进。

测试采用 tempfile 创建隔离目录。单元测试用虚拟平台资料验证内置保护根，集成测试在临时目录验证执行门禁；真实系统与敏感位置用于只读的拒绝计划测试。故障注入后端与测试策略构造器仅在测试构建启用。

写入阶段的夹具用 `tempdir_in` 创建于经检查的非 A/B 测试根，并避开现有项目整体。CI 通过 `FILE_TIDY_TEST_ROOT` 指定位置并检查规范化路径；macOS `/private` 和 Windows AppData 下的默认临时目录按区域策略处理。测试根不可用时记录跳过原因。

| A07 | B 路径、正文、完整性哈希进入普通 tracing 或扫描导出 | 普通日志无内容/哈希；必要审计仅本地 journal；默认扫描无 B 内容指纹 | 1/3a |

| A09 | 从公开 API 直接执行，伪造/导入 ApprovedPlan 或布尔 confirmed | 不能获得通用写能力；导入仍重新审阅确认与授权 | 2/3a |
| A10 | 规则含绝对路径、`..`、脚本，未知 schema 或整数溢出 | 解析/计划拒绝，不执行外部代码或逸出目标 | 1/2 |
| P01 | 子链接、根链接、断链、父链接、链接指向 A/外部目录 | 不遍历；仅合法的显式链接删除去掉链接本身，目标完全不变 | 1/3b/3c |
| P02 | Windows junction、volume mount point、未知 reparse tag | 显式 FILE_ATTRIBUTE_REPARSE_POINT 分支；不递归、不哈希、不盲目删除 | 1/3a |
| P03 | 项目 marker 是目录或 worktree 文件；依赖目录和 .app | 不拆内部文件；整体操作有警告和完整清单 | 1/2 |
| P04 | 目录含隐藏项、B 项、嵌套授权根、工具库或挂载根 | 不借父目录间接搬走/删除；需要展开或直接拒绝 | 2/3b/3c |
| P05 | 活跃 DB/WAL、VM、容器存储、未知伴随文件 | 核验静止状态及伴随文件完整性；条件不满足则拒绝迁移 | 2/3a |
| P06 | Unix 非 UTF-8 字节、Windows 非正常 Unicode code units | 扫描/计划/执行/journal/恢复无损往返，展示字符串不参与操作 | 1/3a |
| P07 | 长路径、CON/NUL、尾空格/点、ADS、Unicode NFD/NFC、大小写敏感目录 | 非法生成名拒绝；合法原始路径保留；原子冲突无覆盖 | 2/3a |
| P08 | 终端换行/ESC/双向控制符、HTML 标签文件名、非整数安全范围的大小 | 无终端/HTML 注入；大小准确；按 ID 操作 | 1/4 |

## 计划 执行 与故障

| ID | 验收情景 | 预期结果 | 首次阶段 |
| --- | --- | --- | --- |
| E01 | build_plan/dry-run/取消预览，对文件系统调用做 spy | 0 写调用，不创建目录、锁、快照或临时文件 | 2 |
| E02 | 单项取消、改目的地、增删选择、超时、修改快照、重放确认 | 原确认失效；重新预览；无法只改展示后静默执行 | 2/3a |
| E03 | 100/101 个叶子、10 GiB 边界、大目录只作为一项 | 阈值按真实叶子统计，超出时二次确认；大小无溢出 | 2 |
| E04 | 目标同名文件/目录/大小写等价名、执行前竞态创建目标 | 原件永不覆盖；候选名先预览；执行冲突后跳过重新计划 | 2/3a |
| E05 | 源类型、身份、大小、修改时间变化；父目录替换/挂载变化 | 该项跳过；内容目录变化整项作废；不逃出授权 | 3a |
| E06 | 复制前空间不足，写中 ENOSPC/配额、注入短写/I/O、源读取失败 | 不发布副本；源原样；只清理身份相符的本次半成品 | 3a |
| E07 | 篡改临时副本、哈希不符、源读取时被改、元数据恢复失败 | 校验失败不提交；必需元数据不完整不删除源；记录原因 | 3a |
| E08 | 注入 EXDEV、真实双卷、Windows ERROR_NOT_SAME_DEVICE | 仅 rename 的跨设备错误触发 copy→verify→remove；授权独立复核 | 3a |
| E09 | 注入 EACCES、openat2 逃逸 EXDEV | 不误触发跨卷复制回退 | 3a |
| E10 | 跨卷目标校验成功而源删除失败、源删除后 journal 失败 | 前者保留源并标部分完成；后者标记 NeedsRecovery 并对账 | 3a |
| E11 | 跨卷目录复制第 N 项失败、源中新增项、隔离提交失败 | 原源树保持原样；不递归删源；暂存清理或待恢复 | 3b |
| E12 | 同卷目录移动、大小写更名中间态、源目标互为祖先或循环 | 合法 rename 不覆盖；循环/重叠拒绝；中间态可恢复 | 3a |
| E13 | 写状态库前失败、快照落盘失败、磁盘满、数据库锁定 | 首次变更前失败则零执行；中途停止后续条目 | 3a |
| E14 | 每个 intent/文件同步/发布/源移除/结果落盘边界强杀进程 | 重启只读对账准确，恢复须当前授权/确认，操作不重复、不误删 | 3a |
| E15 | CLI 与 GUI 同时提交、同批再次提交、授权撤销与执行竞争 | 单写者、幂等、撤销到安全检查点后无后续写入 | 3a/4 |
| E16 | 拷贝文件权限/mtime、ACL/xattr/资源叉/ADS，稀疏及 clone 文件 | 明确保留能力；不扩权；不虚报空间或保留成功 | 3a |
| E17 | 半成品清理权限撤销或半成品被替换成别人的文件 | 不越权清理、不删除替换对象；记录恢复需求 | 3a |

## 撤销 隔离 与永久删除

| ID | 验收情景 | 预期结果 | 首次阶段 |
| --- | --- | --- | --- |
| D01 | move/rename/copy 批次和单条撤销，逆序依赖 | 生成逆向计划并确认；副本默认移入授权区内隔离；依赖冲突拒绝；journal 追加原事实不改写 | 3a |
| D02 | 副本改内容、同大小同 mtime 改内容、同内容但换 inode、目录多文件 | 拒绝复制撤销；无法校验身份则拒绝；B 读取重新确认 | 3a |
| D03 | 软删普通文件/完整目录，逐项和按批恢复，原路径冲突 | 源原路径移除、payload 完整；恢复不覆盖，冲突先重新预览 | 3b |
| D04 | 默认 30 天、配置保留期、过期、程序启动 | 仅提醒；绝不自动 purge；仍可恢复 | 3b |
| D05 | 删除挂载根、授权根、工具状态/journal/config、含它们的父目录 | 直接拒绝；授权和确认不能放宽 | 3b/3c |
| D06 | 删除目录中新增/删除/替换子项、无权枚举、隐蔽子项 | 整目录计划失效，重新生成；不先删可见部分 | 3b/3c |
| D07 | purge 载荷被替换/加新文件、源授权已撤销、清理越界 | 清单失效；拒绝越权；不能借隔离区旧凭据绕过 | 3c |
| D08 | 没有 --permanent、无完整清单/总大小、错误确认词/数/挑战码 | 不执行永久删除；UI/CLI/日志均有不可撤销标识 | 3c |
| D09 | 10/11 个叶子与 1 GiB 边界，B + 永久 + 大计划 | 严格阈值与各项确认均生效；不能用一次确认替代所有条件 | 3c |
| D10 | 目录永久删除第 N 叶失败、取消、断电、源变化 | 已删除部分如实记录不可恢复；未处理部分不误报已删或可回滚 | 3c |
| D11 | 永久删除链接，链接目标含用户数据/A | 仅 unlink 已验证的链接；目标不变；未知 reparse 拒绝 | 3c |

## GUI CI 与平台验证

| ID | 场景 | 验证方法与目标 |
| --- | --- | --- |
| G01 | 未授权窗口、远程 origin、未注册命令、fs/shell/HTTP 请求 | 构建 Tauri ACL 并运行拒绝测试 |
| G02 | 没有 native path 的展示名称，伪造条目 ID/批准状态 | 后端查对象与计划并重新授权，不接收任意展示路径写请求 |
| G03 | 产品离线 | 发布版网络监测，无外部连接/遥测/更新；云占位不水合 |
| G04 | 树图、计划、授权、隔离、撤销及永久危险入口 | 人工交互与自动截图/端到端核对，颜色之外有文字与键盘可访问性 |
| C01 | Windows/macOS/Linux | 阶段 5 GitHub Actions 矩阵真实执行 fmt、clippy -D warnings、test --locked、cargo audit；GUI 独立安装构建依赖 |
| C02 | 平台条件测试 | 分平台记录执行与跳过用例，关联原生运行及手工验证记录 |

后续原生平台验证场景：

- Windows 10 与 11：NTFS/reparse/junction、长路径、保留名、占用句柄、大小写敏感目录、ACL、真实双卷错误。在 Windows 10 与 11 VM/实机分别记录系统版本和文件系统。junction 使用普通账户创建，symlink 按所需权限单独执行或记录跳过。
- macOS：APFS 大小写敏感/不敏感卷、NFD/NFC、firmlink、RENAME_EXCL、外接 exFAT、TCC 拒绝、完全磁盘访问权限、资源叉/xattr。使用临时磁盘映像和普通测试账户，分别记录 CLI 与打包 GUI 的权限表现。
- Linux：ext4/btrfs、bind mount、openat2、旧内核/不支持 NOREPLACE 的文件系统、用户配额、FUSE。实际跨卷/挂载夹具需外部准备，可使用预设挂载或用户 namespace；产品本身和默认测试都不使用 sudo。
- 系统回收站：作为独立候选功能评审三平台落点与恢复 API。
- 崩溃持久性：分别执行进程强杀、故障注入及虚拟机硬断电场景，记录各持久化边界的恢复结果。

阶段 5 保存各平台 CI 日志、手工步骤、系统与卷类型，以及待补测项。
